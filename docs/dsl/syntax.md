# Синтаксис TextCAD DSL v0

## Файл

- кодировка UTF-8;
- рекомендуемое расширение `.textcad`;
- один файл содержит один документ;
- первая выполняемая форма должна быть `textcad`;
- регистр идентификаторов имеет значение.

```text
[textcad version=1 default-length=mm default-angle=deg]
```

## Комментарии

Комментарий начинается с `;` и продолжается до конца строки.

```text
; Пластина основания
[let base [box size=[100mm 60mm 8mm]]]
```

Комментарии не участвуют в выполнении и должны сохраняться formatter-ом.

## Формы

Основная конструкция языка — форма в квадратных скобках:

```text
[command positional-argument named-argument=value]
```

Формы могут быть вложенными:

```text
[let body
  [extrude profile length=20mm]
]
```

Parser сначала строит общее синтаксическое дерево списков. Значение первой
позиции интерпретируется как имя команды только на семантическом этапе.

## Идентификаторы

Рекомендуемая грамматика:

```text
[A-Za-z_][A-Za-z0-9_-]*
```

Примеры:

```text
body
motor-bracket
profile_01
XY
```

Зарезервированные литералы:

```text
true false null
```

## Строки

Строка заключается в двойные кавычки.

```text
label="Motor bracket"
```

Обязательные escape-последовательности:

```text
\"  \\  \n  \r  \t
```

## Числа и физические величины

Числа используют точку как десятичный разделитель:

```text
10
-4.5
0.125
```

Физическая единица записывается без пробела:

```text
20mm
-12.5mm
45deg
```

Минимальные единицы v0:

| Категория | Единица |
|---|---|
| Длина | `mm` |
| Угол | `deg` |
| Безразмерное значение | без суффикса |

Bare number допустим для параметра длины или угла только при наличии
`default-length` или `default-angle` в заголовке документа. Formatter должен
предпочитать явные единицы в публичных примерах.

## Векторы

Вектор — список значений без имени команды:

```text
[10mm 20mm]
[0mm 0mm 1mm]
```

Ожидаемая размерность определяется командой:

- `Point2` — два значения длины;
- `Point3` — три значения длины;
- направление — три безразмерных значения.

## Именованные аргументы

```text
[line start=[0mm 0mm] end=[40mm 0mm]]
```

Правила:

- имя и значение разделяет `=` без обязательных пробелов;
- повтор одного именованного аргумента является ошибкой;
- неизвестный аргумент является ошибкой;
- порядок именованных аргументов не влияет на результат;
- formatter использует канонический порядок из справочника команды.

## Упрощённая грамматика

```text
document       = trivia, form, { trivia, form }, trivia, EOF ;
form           = "[", trivia, identifier, { trivia, argument }, trivia, "]" ;
argument       = namedArgument | value ;
namedArgument  = identifier, trivia, "=", trivia, value ;
value          = form | list | string | quantity | number | boolean | identifier ;
list           = "[", { trivia, value }, trivia, "]" ;
quantity       = number, unit ;
unit           = "mm" | "deg" ;
boolean        = "true" | "false" ;
trivia         = { whitespace | comment } ;
comment        = ";", { anyCharacterExceptNewline } ;
```

`form` и `list` имеют одинаковые разделители. Parser хранит их как общие list
nodes; различие определяется контекстом и первым элементом списка.
