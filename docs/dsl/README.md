# TextCAD DSL

Статус: **экспериментальное исполняемое ядро**. Parser, Semantic и Evaluator
реализованы; актуальный список работающих команд указан в [commands.md](commands.md).
Заголовок документов — `version=1`, старые файлы совместимы.

TextCAD DSL — компактный source-first язык описания параметрических CAD-моделей.
Текст `.textcad` является единственным источником истины. Дерево операций,
Replicad-геометрия, mesh для Three.js и диагностические сообщения являются
производными данными.

## Цели v0

- одинаково удобное представление модели для человека, GUI и AI;
- детерминированное воспроизведение модели из текста;
- однозначные имена операций и явные ссылки между ними;
- физические единицы в исходном коде;
- связь каждого результата с диапазоном исходного текста;
- сохранение последней успешно построенной модели при ошибке;
- минимальная реализация без общего языка программирования.

## Не входит в v0

- пользовательские функции, циклы и условия;
- модули и импорты;
- геометрические ограничения эскиза;
- сборки;
- постоянные топологические ID и селекторы generated-by;
- автоматическое выполнение кода, созданного Chat, без подтверждения.

Согласованный набор из 35 команд реализован: контуры и рабочие плоскости,
extrude/revolve/loft, булевы операции, fillet/chamfer/shell, преобразования,
два вида массивов, селекторы edges/faces/vertices, отверстия и геометрическая резьба.
Ограничения операций и точный синтаксис перечислены в commands.md.
Отдельные объёмные примитивы
`box`, `cylinder`, `cone`, `sphere`, `torus` в согласованное ядро не входят.

## Конвейер

```text
DSL source
    ↓
Parser → AST с source spans
    ↓
Semantic → проверенная программа
    ↓
Evaluator → Replicad values
    ↓
EvaluationResult
    ├─ roots
    ├─ artifact graph
    ├─ feature tree
    ├─ mesh
    └─ diagnostics
```

GUI и Chat не изменяют Replicad или Three.js напрямую. Они предлагают изменение
DSL-текста, которое проходит через тот же parser и evaluator.

## Текущая реализация

Parser и Semantic выполняются до построения геометрии. Source пересчитывается
при изменении, дерево показывает эскизы, операции и зависимости. Только `root`
публикует геометрию во Viewport. Булевы операции проверяются CAD-ядром; пустой
или некорректный результат не заменяет последнюю успешно построенную модель.
