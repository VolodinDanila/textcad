# Диагностика TextCAD DSL

## Формат

Каждая диагностика содержит:

```text
code
severity
message
sourceSpan
revisionId
relatedSpans[]
```

`sourceSpan` включает начальные и конечные offset, line и column. Line и column
показываются пользователю начиная с 1.

## Severity

| Severity | Поведение |
|---|---|
| `error` | выполнение текущей ревизии прекращается |
| `warning` | выполнение продолжается |
| `info` | информационное сообщение |

## Группы кодов

| Префикс | Категория |
|---|---|
| `TCD-P` | parser/tokenizer |
| `TCD-S` | semantic analysis |
| `TCD-G` | geometry/kernel |
| `TCD-R` | runtime/environment |

## Базовые коды v0

| Код | Описание |
|---|---|
| `TCD-P001` | незакрытая квадратная скобка |
| `TCD-P002` | неожиданный токен |
| `TCD-P003` | незакрытая строка |
| `TCD-P004` | некорректное число или quantity |
| `TCD-S001` | неизвестная команда |
| `TCD-S002` | неизвестная ссылка |
| `TCD-S003` | повторное объявление имени |
| `TCD-S004` | отсутствует обязательный аргумент |
| `TCD-S005` | неизвестный или повторный аргумент |
| `TCD-S006` | несовместимые типы или единицы |
| `TCD-S007` | forward reference запрещён |
| `TCD-S008` | отсутствует root |
| `TCD-G001` | профиль не замкнут |
| `TCD-G002` | соседние кривые не соединены |
| `TCD-G003` | профиль самопересекается |
| `TCD-G004` | недопустимая дуга или окружность |
| `TCD-G005` | Replicad/OpenCascade не построил операцию |
| `TCD-G006` | операция не оставила объёмного тела: пустое пересечение, полное вычитание или контакт без объёма |
| `TCD-G007` | проверка OpenCascade обнаружила некорректную топологию результата |
| `TCD-R001` | CAD-ядро не инициализировано |
| `TCD-R002` | результат устаревшей ревизии отброшен |

## Пример

```text
error TCD-S002 at 18:16
Unknown reference "profiel". Did you mean "profile"?

[let body [extrude profiel length=20mm]]
                   ^^^^^^^
```

## Поведение UI

- parse errors показываются сразу;
- evaluator не запускается при parse или semantic errors;
- geometry errors привязываются к форме, вызвавшей Replicad;
- последняя успешная модель остаётся в Viewport;
- статус явно сообщает, что Source и Viewport не синхронизированы;
- переход по диагностике выделяет соответствующий диапазон Source;
- новый успешный результат очищает устаревшие ошибки предыдущей ревизии.

## Сообщения ядра

Технические исключения OpenCascade не должны напрямую показываться пользователю.
Evaluator сохраняет исходную ошибку для debug log, а в UI возвращает устойчивый
код и понятное сообщение с контекстом команды.
